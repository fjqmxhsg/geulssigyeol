글씨결 · 운영 플레이북

24글자로 폰트를 주고,
공유 카드로 팔로워를 받는다 인스타 계정 성장 도구로 글씨결을 굴리는 방법. 처음 4주 계획과 판단 기준.

글씨결은 앱이 아니라 미끼입니다. 사람들은 "내 글씨가 폰트가 된다"에 반응하고, 결과물(공유 카드)을 올리면서 계정을 태그합니다. 그 태그가 팔로워가 됩니다.

1. 한 문장 전략

무료로 폰트를 만들어 준다 → 자랑하고 싶은 카드를 준다 → 카드에 우리 계정이 찍혀 있다 → 태그하면 리포스트해 준다 → 다음 글자 이벤트는 팔로워만 먼저 받는다.

돈 드는 것이 없습니다. 서버도 없고, 광고도 없습니다. 비용은 딱 하나, 매일 리포스트하고 댓글 다는 시간입니다.

2. 성장 루프

1프로필 링크로 앱 열기
(3분 안에 폰트 완성)
2공유 카드 저장
(4:5, 계정·해시태그 자동 삽입)
3스토리·피드에 올리고
계정 태그
4리포스트 + 댓글
→ 친구들이 링크 타고 1번으로

이 루프에서 앱이 자동으로 해주는 것은 2번뿐입니다. 3번은 사용자가, 4번은 운영자가 합니다. 4번을 빠뜨리면 루프가 끊깁니다. 태그된 카드는 24시간 안에 반드시 리포스트하세요.

3. 왜 먹히나

  • 결과물이 "내 것"이라서. 남의 콘텐츠를 공유하는 게 아니라 내 글씨를 자랑하는 겁니다. 공유 저항이 거의 없습니다.
  • 진입이 낮아서. 앱 설치 없음, 회원가입 없음, 24글자 3분. 프로필 링크 한 번이면 끝.
  • 비교하고 싶어져서. "내 글씨 vs 네 글씨" 구도가 자연스럽게 생깁니다. 친구 태그를 부릅니다.
  • 다음이 있어서. 기본 24자 → 영문·숫자 → 쌍자음 → (앞으로) 이모지·특수문자. 팔로우할 이유가 계속 생깁니다.

4. 배포 전 체크리스트

  • CONFIG에 내 인스타 아이디·프로필 주소·해시태그 넣기 (README 2번)
  • https 주소로 배포하고 폰에서 직접 24자 써서 .ttf 받아보기
  • 공유 카드 만들어서 내 계정이 제대로 찍히는지 확인
  • 인스타 프로필 링크에 배포 주소 넣기
  • 프로필 소개에 "내 글씨 폰트 무료 → 링크" 한 줄 넣기
  • 해시태그 검색해서 아무도 안 쓰는 태그인지 확인 (겹치면 바꾸기)
  • 고정 게시물 1개: 앱 사용법 릴스 또는 캐러셀

5. 첫 4주 계획

주차할 일목표
0주
준비		배포, 프로필 링크, 고정 게시물. 내 글씨로 카드 5장 만들어 두기.링크 타고 폰트 완성까지 폰에서 문제 없이 됨
1주
씨앗		매일 내 카드 1장 + 릴스 1개(24자 쓰는 과정 타임랩스). 친구·지인 10명에게 직접 링크 보내고 카드 올려 달라고 부탁.태그된 카드 10장. 첫 리포스트.
2주
루프 확인		태그된 카드 전부 리포스트. 댓글에 "○○님 글씨 ㅋ 진짜 이렇게 쓰세요?" 식으로 대화. 카드 잘 나온 사람 피드에 소개.지인 아닌 사람의 태그가 나오기 시작
3주
비교 콘텐츠		"같은 문장, 다른 글씨" 캐러셀(팔로워 카드 모음). "글씨로 성격 보기" 같은 가벼운 밈.저장·공유 수가 좋아요 수를 넘는 게시물 1개
4주
첫 이벤트		"쌍자음·ㅐ·ㅔ 7자 추가" 를 팔로워 한정 공지. 참여자 카드 모아 릴스.이벤트 게시물 → 팔로우 전환 측정

6. 콘텐츠 유형

매일 (택 1)

  • 리포스트: 태그된 카드. 그냥 올리지 말고 한 줄 코멘트 붙이기.
  • 과정 릴스: 24자 쓰는 손 + 완성 문장 타이핑. 15초. "3분이면 됨" 자막.

주 1~2회

  • 비교 캐러셀: 같은 문장을 팔로워 5명 글씨로. 첫 장은 질문("누구 글씨가 제일 나답나요?").
  • 활용 예시: 만든 폰트로 굿노트 다이어리, 캡컷 자막, PPT 표지. "폰트 받아서 여기 씁니다" 증거.

월 1회

  • 글자 이벤트: 새 단계 오픈(영문 → 쌍자음 → 이모지 → 특수문자). 팔로워 먼저 공지.
  • 베스트 카드: 이달의 카드 9장 모아 그리드 한 장.

7. 리포스트 규칙

  • 태그된 카드는 24시간 안에 스토리 리포스트. 예외 없음.
  • 피드에 올릴 때는 본인에게 DM으로 한 번 물어보고 올립니다. 카드에 이름이 찍혀 있기 때문입니다.
  • 리포스트할 때 항상 글씨에 대한 구체적인 한 마디를 붙입니다. "ㅇ이 동그랗네요", "받침이 작아서 귀여움". 봇처럼 보이면 끝입니다.
  • 카드가 안 예쁘게 나온 사람은 "펜 굵기 '굵게'로 바꿔 보세요" 같은 해결책 댓글. 그 사람이 다시 만들어 올리면 두 번 노출.

8. 볼 숫자

루프가 도는가태그된 카드 수 / 주. 이게 안 늘면 나머지는 의미 없음.
링크가 먹히는가프로필 링크 클릭 수 (인스타 인사이트). 클릭 대비 태그 비율.
팔로우로 바뀌는가이벤트 게시물 도달 대비 팔로워 증가.

좋아요 수는 보지 마세요. 저장·공유·태그만 봅니다. 이 셋이 알고리즘이 밀어주는 신호이고, 루프가 도는 증거입니다.

9. 막히면

증상원인 추정조치
링크 클릭은 있는데 태그가 없다폰트는 만들었지만 카드까지 안 감. 또는 카드가 안 예쁨.완성 화면 첫 버튼을 카드로 바꾸는 것 검토. 기본 문장을 더 자랑하고 싶은 문장으로. 펜 굵기 기본값 "굵게" 테스트.
태그는 있는데 팔로우가 안 는다리포스트만 하고 팔로우할 이유를 안 줌.이벤트 주기 당기기. 프로필에 "다음 이벤트: ○월 ○일" 명시.
지인 이후로 안 퍼진다비교·밈 콘텐츠 부족. 남의 카드를 보고 "나도"가 안 생김.3주차 비교 캐러셀 집중. 글씨 유형 밈("ㅇ 큰 사람 특") 시도.
폰트가 이상하다는 댓글칸 밖으로 작게 썼거나 획을 여러 번 나눠 씀."칸 안에 크게, 한 획으로" 안내 릴스. 잘 쓴 예/못 쓴 예 비교.

10. 다음 단계 (팔로워 1천 이후)

  • 글자 단계 추가: 이모지·특수문자·한자 일부. src\app.js의 STAGES에 한 줄 추가하면 됩니다.
  • 커플·친구 폰트: 두 사람 글씨를 번갈아 조합. 태그를 두 배로 부릅니다.
  • 굿즈: 본인 폰트로 찍는 스티커·엽서. 첫 수익 모델 후보.
  • 브랜드 협업: 다이어리·문구 브랜드에 "고객 글씨 폰트 이벤트" 제안. 앱은 ?brand=&ig= 파라미터로 이미 다른 계정용으로 바뀝니다.

11. 하지 말 것

  • 사용자 글씨 데이터를 모으려고 서버를 붙이지 않기. "폰에만 저장"이 신뢰의 핵심입니다.
  • 앱 안에서 팔로우 강제(팔로우해야 다운로드) 하지 않기. 앱은 무가입·무료여야 합니다. 팔로우 조건은 12번의 댓글 자동 DM 링크에만 붙입니다.
  • 리포스트 없이 하루 넘기지 않기. 태그한 사람이 무시당했다고 느끼면 그 사람의 친구들도 안 옵니다.

12. 릴스 → 댓글 자동 DM (2026-09-11 추가)

링크를 프로필이 아니라 DM으로 보냅니다. 지금 계정의 병목(프로필 방문 → 팔로우 0.9%)을 거치지 않는 경로입니다.

릴스 "24글자 쓰면 내 글씨가 폰트 됨" → 댓글에 '글씨' → 리틀리(무료)가 자동 답글 + DM(앱 링크 버튼, 팔로우 조건 켬) → 앱에서 응원 문구 골라 카드 → 스토리 태그 → 24시간 안에 리포스트.
  • 앱 쪽 준비는 끝났습니다. 첫 화면 예시가 응원 문구 12개를 순환하고(탭하면 바뀜), 완성 화면에 같은 문구 칩이 있어 한 번 눌러 카드로 만듭니다. 문구 목록은 src\app.js의 CHEER_LINES.
  • 키워드는 '글씨' 두 글자. 릴스 마지막 장과 캡션에 따옴표를 붙여 딱 두 글자로 보여줍니다.
  • 툴은 리틀리(무료, 팔로우 조건 무료). DM이 막히면 매니챗으로 같은 세팅, 둘을 동시에 켜지 않습니다.
  • 릴스 콘티 7장, 리틀리 세팅 순서, DM·자동 답글 문구, 첫 7일 운영, 깔때기 6단 측정은 ht_bangbang_instatoon\04_작업물\20260911_글씨결_응원카드_릴스_자동DM_세팅.md. 실험 카드는 실험_로그.md E-08.
